# CashFlow WB — Google Apps Script Веб-приложение

## Установка (5 минут)

### Шаг 1 — Открой Гугл Таблицу
Открой свою таблицу **ИП Баширов ИР 2026 - @CashFlowWB**

### Шаг 2 — Открой редактор скриптов
В меню таблицы: **Расширения → Apps Script**

### Шаг 3 — Создай файлы
В редакторе Apps Script:

**Файл Code.gs** (уже существует — замени всё содержимое):
- Скопируй содержимое файла `Code.gs` из этой папки

**Файл Index.html** (создай новый: Файл → Создать → HTML):
- Назови его `Index`
- Скопируй содержимое файла `Index.html` из этой папки

### Шаг 4 — Разверни как веб-приложение
1. Нажми **Развернуть** → **Новое развёртывание**
2. Выбери тип: **Веб-приложение**
3. Настройки:
   - Описание: `CashFlow WB Dashboard`
   - Выполнять от имени: **Я (ваш аккаунт)**
   - Доступ: **Все** (или только ты)
4. Нажми **Развернуть**
5. Скопируй URL веб-приложения — это твой дашборд!

### Шаг 5 — Открой дашборд
Перейди по скопированному URL — увидишь:
- 🏠 **Главная** — сводка: выручка, прибыль, расходы
- 💰 **Реализации** — топ товаров по выручке WB
- 🏪 **Хранение** — платное хранение по товарам
- 📣 **Реклама** — ВБ.Продвижение статистика
- 📝 **Операции** — движение денег (ДДС)
- 📊 **P&L / ДДС** — прибыли и убытки
- 🧮 **Юнитка** — юнит-экономика по товарам
- 📦 **Артикулы** — список товаров

## Обновление данных
После загрузки новых данных через WB API кнопку «🔄 Обновить» на Главной.

## Требования к листам
Веб-приложение читает данные из этих листов:
- `⚙️ Настройки` — компания, метрики
- `📊 P&LДДС` — P&L и ДДС
- `💰 Отчет` — сводный отчёт
- `📝 Операции` — транзакции ДДС
- `🧮 Юнитка` — юнит-экономика
- `📦 Артикулы` — список товаров
- `🚚 Поставки` — поставки
- `Реализации (исх.)` — отчёт WB реализаций
- `Платное хранение` — хранение
- `ВБ.Продвижение` — реклама
