# 🌙 Ramadan Widget for iOS (Scriptable)

Minimalistic Apple-style Ramadan widget for iPhone.
Supports Home Screen and Lock Screen widgets.

## ✨ Features
- Days until Ramadan
- Ramadan day counter
- Hijri date
- Quotes & daily reminders (JSON)
- Iftar & Suhoor countdown
- Automatic prayer times (location-based)
- API caching (battery friendly)
- Light / Dark gradients
- Arabic calligraphy headers

## 📦 Widget Sizes
- Home Screen: Small / Medium / Large
- Lock Screen: Inline / Circular / Rectangular

## 🚀 Installation
1. Install **Scriptable** from App Store
2. Create folder `RamadanWidget`
3. Copy files from `src/`
4. Create `data/quotes.json` and `data/reminders.json`
5. Add Scriptable widget to Home / Lock Screen

## 📝 Customization
- Edit quotes & reminders in JSON
- Prayer times calculated automatically
- Uses AlAdhan API
- Cached once per day
